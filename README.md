# High-Yield: The Real Estate Simulation

High-Yield is a playable, deterministic real-estate management simulation. Buy
assets, monitor tenants, resolve maintenance, track market conditions, and grow
from a duplex into a larger portfolio. The app runs without third-party runtime
dependencies and saves progress in the browser.

## Run locally

```bash
npm start
```

Open <http://localhost:4173>. Run the automated checks with `npm run check`.

## Included systems

* Deterministic economic clock with live property valuations and weather.
* Portfolio cash flow, occupancy, condition, and health analytics.
* Tenant satisfaction and payment-risk directory.
* Actionable maintenance work orders with real cash consequences.
* Underwritten acquisitions using equity and debt financing.
* Browser persistence, simulation speed controls, and responsive layouts.

The full implementation blueprint remains available in the
